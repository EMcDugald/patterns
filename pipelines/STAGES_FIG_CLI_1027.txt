# movie, plus the stage-timing diagram and the redrawn jump grid over every core of the core_track run.
# New script: nucleation_stages_figures.py. Put it in ~/patterns/pipelines beside core_track_time_series.py,

# Everything this list writes is named 1027_stages_* (folders and zips), and every file inside begins with stages_.
# Needs the core_track results of 27 Oct (results/1027_core_track_fine_dt025 and results/1027_core_track_coarse_dt02).
# Run from ~/patterns/pipelines in ResearchS25:  cd ~/patterns/pipelines; bash STAGES_FIG_CLI_1027.txt 2>&1 | tee results/1027_stages_run.log
